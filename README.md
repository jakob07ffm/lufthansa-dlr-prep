# Lufthansa DLR Prep

Native macOS SwiftUI app zur Vorbereitung auf ausgewählte Bereiche des Lufthansa-DLR-Pilotentests.

## Starten

1. Repository auf einem Mac mit Xcode 15 oder neuer öffnen.
2. `Package.swift` in Xcode öffnen.
3. Das ausführbare Target `LufthansaDLRPrep` auswählen und starten.

## Funktionen

- Trainingsmodule für Geschwindigkeit, Mathematik, Merkfähigkeit und Konzentration
- Einstellbare Dauer, Schwierigkeit und Reizgeschwindigkeit
- Einstellungen werden lokal über `AppStorage` gespeichert
- Erste Übungseinheit mit Countdown und Pause/Weiter

Die enthaltenen Übungen sind ein konfigurierbares Trainingsgerüst und keine offizielle Simulation oder Prüfungsvorlage der Lufthansa bzw. des DLR.
